## Features

- **Live email existence check** (Sign Up form) — validates in real time as the user types; detects if the email is already registered and prompts them to sign in before even typing a password
- **Sign Up** with email & password (`createUserWithEmailAndPassword`)
- **Sign In** with email & password (`signInWithEmailAndPassword`)
- **Auth Gate** — a `StreamBuilder` on `authStateChanges()` that automatically manages authentication state across sessions and restarts
- **Session persistence** across restarts — Firebase automatically retains the signed-in user session
- **Strong password validation** (enforced on both Sign In & Sign Up):
  - Minimum 9 characters
  - At least one uppercase letter (A–Z)
  - At least one lowercase letter (a–z)
  - At least one digit (0–9)
  - At least one special character (`!@#$%^&*` etc.)
- **Firebase error handling** with friendly user-facing messages for all common codes:
  - `weak-password`, `email-already-in-use`, `user-not-found`
  - `wrong-password`, `invalid-credential`, `invalid-email`
  - `too-many-requests`, `network-request-failed`, `operation-not-allowed`
- **Logout with complete controller lifecycle disposal**:
  - Confirmation dialog before signing out
  - Disposes and deletes `HomeController`, `LoginController`, `SignUpController`
  - Cancels debounce timers and disposes all `TextEditingController`s
  - Safely navigates back to the Login Screen with zero red-screen errors or stale state
- **Form validation** (email format, real-time uniqueness, password strength, confirm match)
- **Show/hide password** toggles on all password fields
- **Loading states** on Sign In / Sign Up buttons
- **Branded splash screen** — full-bleed edge-to-edge dark navy/blue gradient matching the Klader brand
- **Branded app launcher icon** — clean cutout of Klader logo on native gradient background
- **Responsive layout** (works on mobile, tablet, macOS desktop, Chrome)

## Architecture

```
lib/
├── main.dart                     # Firebase init + runApp (safe error boundary)
├── firebase_options.dart         # Generated by flutterfire configure
└── app/
    ├── app.dart                  # GetMaterialApp root
    ├── bindings/
    │   └── initial_binding.dart  # AuthService registered permanently
    ├── routes/
    │   ├── app_routes.dart       # Route name constants
    │   └── app_pages.dart        # GetPage definitions
    ├── core/
    │   ├── theme/
    │   │   ├── app_colors.dart   # Colour tokens
    │   │   └── app_theme.dart    # ThemeData (light)
    │   ├── errors/
    │   │   └── auth_failure.dart # FirebaseAuthException → user-friendly message
    │   ├── utils/
    │   │   ├── validators.dart   # Pure form validators (unit-tested)
    │   │   └── app_snackbar.dart # Success / error snackbar helpers
    │   └── widgets/              # Shared UI: AppTextField, PrimaryButton,
    │                             #   AuthScaffold, AuthHeader, ErrorBanner,
    │                             #   ControllerScope
    ├── data/services/
    │   └── auth_service.dart     # Only class that calls FirebaseAuth
    └── modules/
        ├── auth/
        │   ├── auth_gate.dart    # StreamBuilder auth-state switch
        │   ├── login/            # LoginController + LoginView
        │   └── signup/           # SignUpController + SignUpView
        └── home/                 # HomeController + HomeView (logout)
```

**State management / DI / navigation:** [GetX](https://pub.dev/packages/get)

**Key design decisions:**
- `AuthService` is a `GetxService` registered permanently — it outlives any route
- `ControllerScope` binds controller lifecycle cleanly to the widget tree and defers disposal to post-frame, ensuring that route transitions and reactive widgets (`Obx`) unmount without build-time exceptions
- On logout, all controllers (`HomeController`, `LoginController`, `SignUpController`) and their internal `TextEditingController`s and timers are completely disposed, returning the user to a clean, fresh Login Screen
- `AuthGate` with `StreamBuilder` provides the single source of truth for auth state across app restarts

## Setup & Running

### 1. Install dependencies

```bash
flutter pub get
```

### 2. Configure Firebase (already configured for Android & Web)

```bash
# Optional: if re-configuring or adding iOS
flutterfire configure -p klader-machine-test --platforms=android,web
```

### 3. Run the app

```bash
flutter run
```
